# בסיסי נתונים מאפס עד 10 🗄️

**🔗 לאתר: https://maiissh.github.io/db-course/**

אתר לימוד אינטראקטיבי לקורס **מערכות בסיסי נתונים**: 11 שלבים, מהמבוא ועד עצי B+, עם הסברים, ציורים, דוגמאות ומעבדות.

[![תצוגה מקדימה של האתר](preview.png)](https://USERNAME.github.io/db-course/)

## מה יש באתר

| שלב | נושא | מה אפשר לעשות |
|:-:|---|---|
| 0 | מבוא | תרשים מערכת בסיס נתונים, סכמה מול מופע |
| 1 | מודל ER | ציורי ישויות, תכונות, עוצמות קשר והשתתפות |
| 2 | ישות חלשה, טרנרי, ISA | טבלת סימנים מלאה (Elmasri–Navathe) |
| 3 | מודל היחסים | **מעבדת מפתחות זרים**: CASCADE, SET NULL, RESTRICT |
| 4 | המרה מ־ER לטבלאות | 9 הצעדים, כל אחד עם ציור |
| 5 | אלגברה רלציונית | **מעבדה** שמריצה שאילתות צעד אחר צעד |
| 6 | תחשיב יחסים | TRC, DRC והטריק של ∀ |
| 7 | SQL | סדר ביצוע, GROUP BY ו־HAVING בהדגמה |
| 8 | אילוצים, טריגרים, מבטים | לוגיקה תלת־ערכית, פרוצדורות, JDBC |
| 9 | תלויות ונרמול | **מעבדת FD**: סגור, מפתחות, כיסוי קנוני, BCNF, 3NF |
| 10 | אינדקסים וגיבוב | **עץ B+ חי** וגיבוב מתרחב |

בכל שלב יש שאלות לבדיקה עצמית, וההתקדמות נשמרת בדפדפן.
